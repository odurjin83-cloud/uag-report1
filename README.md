# ҮАГ долоо хоногийн тайлан

## Шинэ вэб загвар, дутуу ажлын нөхөлт

`/dashboard` нь хугацаа, хэлтсээр шүүсэн бодит KPI, гүйцэтгэлийн график, сүүлийн ажлууд, шийдвэрлэх асуудлыг харуулна. Нэвтрэх хуудас, цэс, ажил бүртгэл, удирдлага, тайлангийн харагдацыг компьютер болон утасны дэлгэцэд шинэчилсэн.

**Дутуу ажлууд** цэс бүх хугацааны 100%-д хүрээгүй ажлыг жагсаана. Ажилтан үр дүнгээ бичээд **100% болгож илгээх** товч дарна. Батлагдаагүй ажил шууд 100% болж submitted төлөвт орно.

Өмнө баталсан ажил дээр шууд засвар хийхгүй. Нөхөлт тусдаа хүсэлтээр удирдлагад очиж, ажилтанд **100% · Нөхөлт хянагдаж байна** гэж харагдана. Удирдлага **Нөхөлт хянах** цэснээс зөвшөөрвөл эх ажил 100%, approved болж шинэчлэгдэнэ. Тэр хүртэл албан тайлангийн тооцоонд өмнөх баталсан хувь орно. Нэмэлт хүсэхдээ шалтгаанаа бичнэ; ажилтан тайлбарыг харж дахин илгээнэ. Хуучин хувь, үр дүн, хүсэлт, шийдвэрийн түүх report_revisions хүснэгтэд хадгалагдана. Нэг ажилд нэг л хүлээгдэж буй хүсэлт байна.

**Жишээ веб:** `python preview.py` → http://127.0.0.1:5012. Зөвхөн localhost дээр жишээ өгөгдөлтэй тусдаа `tmp/design-demo.db` ашиглана. Удирдлага `demo@uag.mn`, ажилтан `it@uag.mn`; хоёр хэрэглэгчийн туршилтын нууц үг `UagDemo2026!`. Бодит хэрэглэгчийн бааз биш.

**Нэг файлтай хувилбар:** `outputs/uag-system/UAG_single.py` нь шинэ загвар, бүх template, asset, нөхөлтийн урсгалыг агуулна. `python UAG_single.py` гэж ажиллуулна. Эхний асалтаар шинэ баазын админ нууц үгийг асууна.

Хавсаргасан Flask/SQLite кодын өгөгдлийн бүтэц, бүртгэл оруулах, засах, батлах, чиг үүрэг болон хэрэглэгч удирдах ажиллагааг хадгалсан шинэчилсэн хувилбар.

## Ажиллуулах (Windows PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:UAG_ADMIN_PASSWORD = 'Өөрийн-шинэ-нууц-үг'
.\.venv\Scripts\python.exe app.py
```

Хаяг: http://127.0.0.1:5000. Шинэ баазад `admin@uag.mn` хэрэглэгчийг `UAG_ADMIN_PASSWORD` утгаар үүсгэнэ. Хуучин баазын хэрэглэгч, нууц үгийг өөрчлөхгүй. Анхны хэрэглэгч үүссэний дараа орчны нууц үгийг арилгаж болно. Нийтэд мэдэгдсэн хуучин `123456` нууц үгийг шинэ баазад ашиглахгүй.

Админ **Хэрэглэгчид** цэснээс ажилтан, менежер, удирдлагын хэрэглэгч үүсгэнэ. User/manager зөвхөн өөрийн хэлтэст хандана. Admin/management бүх хэлтсийн тайланг харж, батална. Хэрэглэгч нэмэх, устгах эрх зөвхөн admin-д байна.

## Одоо байгаа баазыг ашиглах

`uag_reports_system.db` файлыг `app.py`-тай нэг хавтаст байрлуулах, эсвэл `$env:UAG_DATABASE = 'C:\...\uag_reports_system.db'` гэж тохируулна. Энэ ажлын хавтаст хэрэглэгчийн бодит бааз байгаагүй тул бодит хэрэглэгчид болон тайлангуудыг шилжүүлээгүй.

Эхний асалтаар SQLite backup API ашиглан `*.before-v2-<timestamp>` нөөц үүсгэнэ. `categories` нь `(department,name)` давтагдашгүй хос болон departments гадаад түлхүүртэй болно. Хуучин хүснэгт `categories_legacy_v1` нэрээр хадгалагдана. Тодорхойгүй чиг үүргийг устгахгүй: админ хэлтсийг оноох хүртэл хэрэглэгчийн сонголтод харагдахгүй. Шилжилтийг дахин ажиллуулахад давхар мөр үүсэхгүй.

Хуучин тайлангийн чиг үүргийг таамгаар өөр хэлтэст шилжүүлдэггүй. Жишээ нь МТХэлтсийн хуучин PR ангилалтай тайлан хэвээр үлдэх бөгөөд засахдаа МТ-ийн зөв чиг үүрэг сонгоно. Хуучин `YYYY.MM.DD - N-р 7 хоног` огноог `report_day` болгон хөрвүүлнэ. Танигдахгүй огноо журналд харагдах боловч хугацааны тооцоонд орохгүй. Асуудлын хуучин текстийг явц эсвэл үр дүнгээс автоматаар таамаглахгүй: шинэ `issue` талбарт бүртгэнэ.

## Тайлан ба экспорт

- `/reports`: огноо, удирдлагын хэлтсийн шүүлтүүр, A4 урьдчилан харах, PDF/PPTX.
- User/manager: өөрийн хэлтсийн **1 хуудас**.
- Admin/management: **2 нэгтгэл + сонгосон хэлтэс бүрийн 1 хуудас**. Бүгдийг сонговол кемпийг оруулан **7 хуудас**. Нэг хэлтэс сонговол 3 хуудас.
- PDF ба PPTX хоёулаа A4 босоо. PPTX-ийн хүснэгт, текст, график засварлах боломжтой. PDF ReportLab, PPTX хэрэглэгчийн хүссэн python-pptx хөдөлгүүртэй.
- Явц 100% бол дууссан, 0 < явц < 100 бол явцтай. Эхлээгүй болон тоон бус хуучин явцыг тусад нь үзүүлнэ. Дууссан/явцтай хувийн суурь нь бүх ажил. Дундаж явц нь тоон явцтай ажлуудын энгийн дундаж.
- Тренд нь сонгосон хэлтсийн дуусах огноогоор хязгаарласан сүүлийн 8 долоо хоног. Өгөгдөлгүй долоо хоногийг 0 гэж зохиохгүй. Тайлангийн огноогоор шүүнэ, оруулсан огноогоор биш.
- Хэт урт тайлан нэг A4 хуудсанд багтахгүй бол PDF/PPTX 422 тайлбартай буцаана. Дэлгэц дээр бүх мэдээлэл үргэлжлэн харагдана. Хугацааг багасгах, тайлбарыг товчлох, эсвэл CSV-ээр бүрэн татах боломжтой. Мэдээллийг чимээгүй хасахгүй, уншигдахгүй болтол фонт багасгахгүй.
- `/template.xlsx`-ийн хэлтсийн загварыг Excel импортоор ашиглана. XLSX-ийн эхний хуудас, 6 багана, 500 хүртэл мөр. Явц 0–100 тоо буюу `50%` текст байна. Нэг мөр буруу бол бүх импорт буцаагдана.

Хавсаргасан Excel-ийн `07.20-07.26` хуудасны хэлтэс/ажил/үр дүн/явц/хариуцагч бүтцийг, PPTX-ийн 3, 9–18-р слайдын хэлтсийн тайлангийн бүтцийг лавласан. Чиг үүргийн эцсийн маппинг нь хэрэглэгчийн pasted request-д заасан жагсаалт. Загваруудын өөр өөр хугацааны бодит ажлуудыг шинэ баазад автоматаар оруулаагүй.

## Тохиргоо ба шалгалт

`UAG_SECRET_KEY` байхгүй бол локал `.secret_key` файлд нэг удаа санамсаргүй түлхүүр үүсгэнэ. `UAG_HTTPS=1` нь HTTPS байршуулалтын secure cookie-г идэвхжүүлнэ. Windows дээр Arial ашиглана. Linux дээр DejaVu Sans, эсвэл `UAG_FONT`-д кирилл TTF-ийн зам өгнө. Фонтын тохиргоог PowerPoint ашигладаг машин дээр мөн хангана.

```powershell
python -m unittest discover -s tests -v
```

Тестүүд хэлтэс дамнасан URL/экспорт/засалт, POST ангиллын шалгалт, manager/management эрх, сессийн эрхийг баазаас шинэчлэх, CSRF, HTML escape, хуучин баазын шилжилт, хуудасны тоо, хоосон тайлан, хэт урт тайланг хамарна.

Серверийн ажиллуулах хувилбар: `.\.venv\Scripts\waitress-serve.exe --host=127.0.0.1 --port=5000 --call app:create_app`. Интернетэд байршуулалт энэ ажлын хүрээнд хийгдээгүй.
